WhatsApp + IA sem API oficial

Guia simples de arquitetura — atendimento automatizado via WhatsApp Web

Em uma frase: um serviço bridge mantém o WhatsApp conectado como se fosse o WhatsApp Web; sua aplicação recebe mensagens por webhook, decide (regras + IA) e manda a resposta de volta pelo bridge. Operadores humanos acompanham tudo num painel web.

1. Por que não usar a API oficial?

A Meta Cloud API é a forma oficial: templates aprovados, cobrança por conversa, número verificado. Esta solução usa o protocolo WhatsApp Web (via biblioteca Baileys): o número conecta por QR Code, como quando você abre WhatsApp no navegador ou vincula outro aparelho.

API oficial (Meta)Bridge + WhatsApp Web
Custo por conversa, templatesSem custo Meta; respostas livres
Alta conformidade / escalaSetup rápido; ideal para poucos números
SLA da MetaSessão pode cair; reconectar QR

3. Conexão do número (QR Code)

  1. Subir o serviço bridge (Railway, VPS, etc.).
  2. Gerar QR Code no bridge.
  3. No celular do negócio: WhatsApp → Aparelhos conectados → escanear.
  4. Bridge guarda a sessão e fica online 24h.
  5. Mensagens passam automaticamente — sem usar API Meta.

6. Treinamento (o que a IA “sabe”)

A cada resposta o sistema monta o prompt em tempo real — não depende de um texto fixo desatualizado.

FonteConteúdo
Banco (editável no painel)Nome, personalidade, manual da loja, links, preços, saudação
Código (atualiza com deploy)Cordialidade, catálogo, quantidades, regras de escalação
Histórico da conversaÚltimas N mensagens como contexto

7. Painel do operador

  • Lista de conversas com status (novo, em atendimento, intervenção…)
  • Chat com texto, imagens, áudios e transcrição
  • Botão para pausar a IA e responder manualmente
  • Tela de treinamento: editar nome, saudação, base de conhecimento
  • Humanos e IA compartilham o mesmo número via bridge

8. Mídia (fotos e áudios)

  • Bridge envia mídia em base64 no webhook.
  • Backend grava no banco (blob) ou em storage (S3/R2).
  • Painel exibe via rota autenticada (/api/.../media/:id).
  • Áudio: Whisper transcreve → texto entra no contexto da IA.

9. Múltiplos números

Cada número WhatsApp = uma instância com sessão própria no bridge, config de IA própria e conversas isoladas.

12. Vantagens e limitações

VantagensLimitações
Sem custo por conversa Meta
Respostas livres
Setup rápido (QR)
Controle total do fluxo		 Não é oficial — risco de restrição
Sessão pode cair (reconectar QR)
Bot “ler” pode marcar como lida no celular
Escala menor que Cloud API
Ordem recomendada para um projeto novo: Bridge (QR + echo) → Webhook + banco → Painel básico → IA por cima → Refinamentos (debounce, status, mídia, treinamento).
